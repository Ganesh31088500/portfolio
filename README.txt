# Java Backend Developer Portfolio

A responsive dark-themed portfolio built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalize before publishing
- Replace `Your Name` and `YN` with your name and initials.
- Update the About section with accurate experience, role, and achievements.
- Keep only technologies you can confidently discuss and use.
- Replace the sample project cards with real projects you can publicly share. Add specific outcomes when you can verify them.
- Replace `your-username/your-project` with each real public repository.
- Replace `your.email@example.com`, GitHub, and LinkedIn placeholders with your profiles.
- Do not publish confidential company information, client data, credentials, tokens, or private source code.

## Publish with GitHub Pages (free for public repositories)
1. Sign in to GitHub and create a new repository named `your-username.github.io` for a user site, or create a repository such as `portfolio` for a project site.
2. In the repository, choose **Add file → Upload files** and upload `index.html` (and optionally this README). For a project site, upload it to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes and refresh the Pages settings. GitHub will show the published website URL. A user site typically uses `https://your-username.github.io/`; a project site typically uses `https://your-username.github.io/portfolio/`.
7. Open the published URL on desktop and mobile, and test every navigation, email, and social link.
